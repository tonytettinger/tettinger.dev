This project focuses on building a high-performance, statically generated personal site with a lightweight, code-driven content system—without relying on a traditional third-party CMS.

Content is authored in **MDX** and stored directly in a GitHub repository, enabling versioned, reviewable content updates through standard Git workflows. The site is built with **TypeScript** and **GraphQL-based queries**, allowing content to be queried, filtered, and composed into reusable page templates.

Posts are categorized and dynamically listed, making it easy to extend content sections or introduce new category-based pages without structural changes.

## Key features

-   **Gatsby**
    Static site generation for fast load times, strong SEO characteristics, and a scalable content pipeline. Gatsby’s plugin ecosystem enables flexible data sourcing while keeping runtime complexity low.

-   **MDX-based content architecture**
    Markdown content enhanced with JSX, allowing rich layouts and components while retaining a simple authoring experience.

-   **Chakra UI**
    Accessible, composable React components used to maintain visual consistency and accelerate development.

-   **Netlify**
    Automated builds and deployments triggered by Git updates, providing a simple and reliable publishing workflow.
