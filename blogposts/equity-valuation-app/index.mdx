As part of my MSc thesis in Full Stack Software Development, I built an automated equity valuation application designed to estimate the intrinsic value of publicly listed companies.

The system evaluates companies using a Discounted Cash Flow (DCF) model and monitors daily market movements. When a stock’s market value falls below its estimated intrinsic value by a configurable threshold, the application triggers a webhook that posts an alert to a dedicated Slack channel and publishes a summary view with data visualizations.

The project was self-hosted on a Raspberry Pi and focused on demonstrating rapid, iterative development of a minimum viable product (MVP), end-to-end ownership, and pragmatic architectural decisions.

## Key features

-   **Python & Flask**
    Backend API and server-rendered frontend built for rapid iteration, leveraging a mature ecosystem of libraries.

-   **Tailwind CSS**
    Utility-first styling approach for fast, consistent UI development.

-   **Chart.js**
    Lightweight data visualizations for presenting valuation outputs and trends.

-   **SQLite**
    Simple, low-overhead database suited for self-hosted deployments and prototyping.

-   **Netlify**
    Webhook-based deployment pipeline for publishing reports and summaries.
