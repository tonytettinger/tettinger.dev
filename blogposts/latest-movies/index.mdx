This small **TypeScript-based Next.js** application was built as a lightweight utility for quickly browsing recent movie releases and their ratings when deciding what to watch.

The app consumes data from **The Movie Database (TMDB)** through a dedicated backend API endpoint and renders the UI using **Chakra UI**. It is intentionally kept simple and client-side rendered to ensure users always see up-to-date information with minimal complexity.

The project focuses on clean structure, type safety, and pragmatic technology choices rather than feature completeness. If hosted on Vercel, **Incremental Static Regeneration (ISR)** could be introduced to reduce client-side data fetching, or periodic redeployments could be used to refresh server-side data.

## Key features

-   **TMDB integration**
    Fetches up-to-date movie data via a REST API.

-   **Responsive UI**
    Built with Chakra UI for consistent behavior across screen sizes.

-   **TypeScript**
    Ensures type safety and maintainable application structure.
