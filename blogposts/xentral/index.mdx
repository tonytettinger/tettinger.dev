https://xentral.com

As the founding engineer of the Product Growth Team at Xentral, I led the implementation of a redesigned homepage that accurately reflects the company’s brand and creates a strong first impression.

A key requirement was enabling non-developers to manage content, layout, and styling through a flexible design system powered by Hygraph CMS. Working closely with UX and Product under a tight deadline, we delivered a well-structured, maintainable solution that allows editors to compose modular blocks and adjust component styles directly from the CMS—without sacrificing consistency or performance.

## Key features

-   **Typed GraphQL queries**
    All data fetching is fully typed through GraphQL code generation, improving reliability and developer experience.

-   **Responsive, modular design**
    Page sections are broken down into reusable components that can be customized via predefined UI patterns.

-   **Next.js**
    Enables fast iteration, clean architecture, and strong performance characteristics.

-   **Hygraph**
    Headless CMS providing a scalable and editor-friendly content management workflow.

-   **Tailwind CSS**
    Utility-first styling approach for consistent, modular, and maintainable UI development.
